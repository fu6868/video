# 验证记录（公开脱敏摘要）

## 既有交付记录

项目本机交付文档记录了 2026-09-17 的一次 Windows 实际验收：

- NVIDIA RTX 5060 Laptop GPU 环境下的 small / medium 与 CPU 回退检查。
- 多层目录及 1205 条目扫描、SQLite 迁移、重启恢复、worker 单实例锁。
- 导出竞态不覆盖、ZIP 层级安全、约 130 秒跨窗口音频处理。
- 1366×768 与 1920×1080 桌面布局检查。
- 一批 59 个视频、合计约 32.93 小时的 medium 转写及 SRT 分发；记录称原视频的 SHA-256、大小、修改时间未变。

以上是**既有交付记录的摘要**，不是本次仓库整理重新执行了全部真实素材验收。本次不发布相关素材、课程名称、真实路径、任务 ID、识别文本、数据库或个人审计原件。

## 自动化检查覆盖

`tests/test_baseline.py` 和 `tests/test_product.py` 覆盖文本格式、文件指纹、SQLite、来源与会话边界、队列恢复、扫描去重、导出命名/不覆盖、worker 锁、事件状态及有界音频窗口。测试写入独立临时目录。

测试集包含元数据替身和合成音频，不能用来声称真实语音识别质量。准确率、各种口音/噪声、所有文件系统、所有硬件及极端长视频不在通用保证之内。

本次源码发布的实际检查结果由维护者在发布说明中列出；GitHub Actions 结果需以仓库实际运行状态为准，不预先宣称 CI 通过。

## 当前界面限制

- 文字稿阅读和复制可用，当前搜索主要过滤字幕列表，尚无文字稿定位/高亮。
- 导出 UI 默认处理本批次该类型的全部可用结果；同名不同扩展名冲突应在创建批次时规避，API 可指定 job_ids。
- 当前主要验证桌面 Windows 场景，不承诺移动端、macOS/Linux 安装脚本或公网部署。
